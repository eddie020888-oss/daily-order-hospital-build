# Extended hospital surroundings v1

`campus-surroundings.png` was generated using the built-in image generation tool on 2026-10-27, with the project's existing `reference-hall-v1/09-empty-hospital.png` as the visual reference. The request was to zoom out around a smaller central hospital and extend the same warm cream/teal setting with natural lawns, stone paths and low planting, without text, people or additional hospitals.

Raw source: 1672x941 opaque RGB. SHA256: `b45c05b20589cdcfd87ed66aee79aaf1194e4a01e02341357faa937cb6bb348f`.

This is a fixed-view2.5D painting, not reconstructed3D geometry, collision, navigable land or new building plots. The renderer displays the complete extended painting as one fixed-world surface, preserving the grid/camera coordinate contract. It does not overlay the rectangular historical crop. That original remains in the project as a fallback and independent room-floor reference. Beyond this painting the same opaque surface supplies continuous courtyard detail for extreme camera fitting.
